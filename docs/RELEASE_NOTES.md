**YouTube TV NoAds v0.1.0**

- Includes a ready-to-install APK with a **YouTube TV NoAds** Android TV tile. No separate launcher or original YouTube installation is required.
- Uses the original YouTube artwork with a small **NoAds** label.
- Based on YouTube Android TV **5.30.320 / ARMv7**. Source builds reject mismatched original inputs.
- Tested on **Sony Bravia X90H / Android TV 12**.
- Includes our patcher, local response filter, native hook, build instructions and source checks.

Download **youtube-tv-noads-0.1.0.apk** from the assets below and install it on your TV. SHA-256 checksums are provided in **SHA256SUMS.txt**. Building from source remains optional.
